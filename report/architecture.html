SupportFlow — system architecture

FastAPI calls Supervisor in-process, not over the network. Router and Escalation are Supervisor's own internal nodes; Docs Agent and Web Search Agent are the only parts running as separate OS processes, reached over a real A2A hop. Not shown as a box: the Supervisor process now holds session memory in-process (a LangGraph checkpointer keyed by session_id — see the Supervisor graph diagram), so it is no longer stateless — a restart drops every session's history.
