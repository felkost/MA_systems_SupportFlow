SupportFlow — system architecture

FastAPI and Supervisor are separate code modules, not one file — but FastAPI calls Supervisor as a plain in-process function call, not a network request. Router and Escalation are Supervisor's own internal nodes, not separate services. Docs Agent and Web Search Agent are the only parts that run as their own OS processes, reached over a real A2A network hop.

Model ids per config/models.yaml, snapshot 2026-08-29 — re-check the config before trusting them again.
